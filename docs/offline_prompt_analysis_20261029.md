# Prompt 相关离线分析

更新时间：2026-10-29

本分析只使用已有结果，不发起新的 LLM 请求。

## 1. V3/V4 指标与置信区间

使用 96 个代表作为聚类单位，重复报告随所属代表一起重采样；683 条未进入
去重映射的报告作为固定单例。bootstrap 次数为 5000，随机种子固定。

| Variant | Exact F1 | Cluster-bootstrap 95% CI |
|---|---:|---:|
| V3 | 0.7373 | [0.6190, 0.8344] |
| V4 | 0.7793 | [0.6667, 0.8690] |
| V4 - V3 | +0.0420 | [0.0000, 0.0986] |

解释：

- V4 在点估计上优于 V3。
- 差值区间下界为 0，因此当前数据不足以支持强显著性结论。
- 正文宜使用 “improves” 或 “is associated with an improvement”，不使用
  “significantly improves”。

## 2. 代表级决策变化

| 项目 | false→true | true→false |
|---|---:|---:|
| cjson | 1 | 0 |
| jansson | 0 | 2 |
| 其他 | 0 | 0 |
| **合计** | **1** | **2** |

96 个代表中：

- V3 正确 78 个。
- V4 正确 81 个。
- 仅 3 个代表发生决策翻转。
- McNemar 精确检验 `p = 1.0`。

这 3 个代表经重复报告映射展开后，对应到 1217 条报告上的整体指标变化。
因此 prompt 分析应同时报告代表级变化和报告级加权结果。

## 3. 逐项目结果

V3 与 V4 的 1217 条展开结果中，只有 cjson 和 jansson 出现变化。

| 项目 | V3 TP/FP/FN | V4 TP/FP/FN | V3 F1 | V4 F1 |
|---|---:|---:|---:|---:|
| cjson | 0/0/6 | 6/0/0 | 0.0000 | 1.0000 |
| jansson | 13/21/0 | 13/7/0 | 0.5532 | 0.7879 |

其余 12 个项目在 V3 和 V4 之间没有报告级变化。

## 4. Prompt 长度审计

96 个代表上的 prompt 字符长度：

| Variant | Mean | Median | Min | Max |
|---|---:|---:|---:|---:|
| V3 Direct | 37678.1 | 36238 | 19910 | 51604 |
| V4 Differential | 43499.8 | 42306 | 25592 | 57205 |

V4 prompt 平均比 V3 长约 15.5%。因此 prompt 消融中应固定其他条件，并在
正文中避免把 V3/V4 差异全部解释为“双假设比较”这一句话本身。

## 5. 跨模型 V4 的组级 bootstrap

| Model | Exact F1 | 95% CI | ΔF1 vs main V4 |
|---|---:|---:|---:|
| Qwen3-Coder-Plus（main） | 0.7793 | [0.6649, 0.8654] | — |
| Qwen-Flash | 0.7864 | [0.6771, 0.8724] | [-0.0361, 0.0601] |
| Qwen3.8-Flash | 0.7740 | [0.6618, 0.8631] | [-0.0565, 0.0523] |
| DeepSeek-Flash | 0.7373 | [0.6190, 0.8315] | [-0.0989, 0.0000] |
| GLM-5.3-Flash | 0.7574 | [0.6478, 0.8481] | [-0.0877, 0.0446] |

两个非 Qwen 模型均完成 V4 评估，但差值区间包含 0。跨模型结果应表述为
“不同模型下保持相近的有效性”，而不是“显著优于主模型”。

## 6. 现有重复运行

已有 V3 重复运行记录显示明显的运行间变化，但最终仲裁和修复流程发生过变化，
因此这些记录不能直接作为最终 prompt 稳定性实验。它们说明：

- 不能用一次 temperature=0 运行声称稳定性；
- 正式返修结果应对 P0/P3 至少各重复 3 次；
- 稳定性指标应报告逐代表 flip rate，而不仅是整体 F1 均值。

## 7. Prompt 模板检查

已在 `ckgfuzzer` 环境中执行以下 3 个现有单元测试并通过：

- direct prompt 不被识别为 differential checklist；
- differential prompt 区分 hard/soft misuse；
- prompt 模板不包含项目名或 CVE 字符串。

该检查只针对模板本身；冻结 prompt 中的源码和崩溃日志自然可能包含项目路径，
不能把证据正文中的项目名误判为标签泄漏。
